# Security Policy

CRUFT operates on local files, so safety reports are high priority.

Please report vulnerabilities privately by opening a GitHub security advisory or emailing the maintainer listed on the GitHub profile.

Include:

- CRUFT version or commit
- macOS version
- command used
- cleaner name
- expected vs actual behavior
- whether files were dry-run, tombstoned, or permanently removed

Do not publish proof-of-concept destructive commands until a fix is available.
